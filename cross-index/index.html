What “fully remote” means. The labels describe how coursework is delivered. Nearly every teaching credential still requires in-person student teaching completed locally, so “fully remote” refers to the coursework, not a 100%-remote credential.

Freshness. Delivery formats change term to term; the marker should be treated as “confirm current format with the school.”
