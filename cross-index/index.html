What the labels mean. They describe how coursework is delivered. “Online only” and “in person or online” refer to the class format — nearly every teaching credential still requires in-person student teaching completed locally, whichever format the coursework uses.

Freshness. Delivery formats change term to term; the marker should be treated as “confirm current format with the school.”
